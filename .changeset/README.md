# BritePulse changesets

Use `pnpm changeset` for user-facing CLI, API or behavior changes. Only `britepulse` is publishable; report, integration and fixture packages stay private. Documentation-only changes may use an empty changeset when no release is needed.

`pnpm version-packages` updates versions and changelogs. The current channel is beta, tracked in `pre.json`. See [release how-to](../docs/releases.md) for the prepared version, validation and the explicit publish workflow. Running the version command does not publish.
